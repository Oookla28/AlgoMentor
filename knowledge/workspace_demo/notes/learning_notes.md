# 循环队列学习笔记

## 定义

循环队列是把顺序队列的存储空间首尾相连，使用队头指针 front 和队尾指针 rear 管理元素。队头指针指向队头元素的前一个位置，队尾指针指向队尾元素。

## 判空条件

为了区分队空和队满，常见做法是保留一个空单元。此时队空条件为 front == rear，队满条件为 (rear + 1) % max_size == front。

## 入队与出队

入队时先判断队满，再把新元素放到 rear 的下一个位置，并更新 rear = (rear + 1) % max_size。出队时先判断队空，再更新 front = (front + 1) % max_size。

## 常见错误

一个常见错误是使用 rear == front 同时表示队空和队满，导致无法区分两种状态。另一种错误是忘记对指针取模，导致数组越界。

## 复杂度

循环队列的入队、出队和取队头元素时间复杂度均为 O(1)，空间复杂度为 O(max_size)。循环队列适合固定容量且频繁进出的场景。
